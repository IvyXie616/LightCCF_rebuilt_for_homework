# LightCCF_rebuilt_for_homework
要求：

1.下载Rechorus开源代码并按Rechorus要求配置好框架

2.下载LightCCF.py文件后，放置在Rechorus/src/models/general 目录下，和BPRMF.py等已有模型放置在一起

运行：按照运行Rechorus中的其它现有推荐模型的方法运行即可

参考Rechorus/docs/tutorie=als/GettingStarted.md

python main.py --model_name LightCCF --emb_size 64 --lr 1e-3 --l2 1e-6 --dataset Grocery_and_Gourmet_Food
